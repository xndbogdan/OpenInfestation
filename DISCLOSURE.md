# Disclosure: third-party content in releases

OpenInfestation's own code is MIT or Apache-2.0 ([README](README.md#license)).
Release archives also carry content made by others. This page says what it
is, where it comes from and on what terms.

## The remastered sounds (`Remastered.pak`)

Release archives include `Remastered.pak`, the ambience, weather and crystal
sounds the Vulkan renderer adds. Copy it into your Infestation folder (beside
`PreLoad.dat`); the game reads it from there. Without it the game plays
retail's sound only.

The pak is built by [`scripts/build-remastered-pak.py`](scripts/build-remastered-pak.py)
`--release` from the list in [`ambience/manifest.json`](ambience/manifest.json),
which names every sound's source file, its licence and its processing. Its
`credits.txt` carries the same credits as below.

**Sources**

- **Sonniss GDC Game Audio Bundles** (2015, 2016, 2018, 2019, 2020 and 2026),
  recordings by 344 Audio, 3maze, Airborne Sound, Alexander Kopeikin,
  Articulated Sounds, aXLsound, BlueZone, Borys Peter, Bottle Rocket Fx,
  Charlie Atanasyan, Detunized, Discover Oregon, Eiravaein Works, Filmnoise
  Inc, Game Audio Factory, Hear and Now Sound, Ivo Vicic, Julian Ray, Kevin
  Durr, Kpow Sounds, Leslie Reid, Mattia Cellotto, Pachamedias, Pole
  Position, Sound Ex Machina, Sound Spark LLC, Soundopolis, Soundrangers,
  Submerged Tapes, Timothy McHugh, VSCRL FX and Whatisvalis.
- **Splice**: the crystals' energy-shield impacts, royalty-free sounds
  licensed from Splice.

**Terms, in plain words**

- Both licences let the sounds be used, edited and mixed inside a game or
  other creative work, commercial or not, with no royalties.
- Neither lets the sounds be given away or sold on their own, as sound files
  or a sound library that others could take out and reuse.

That is why the audio is not in this repository: a public repository of the
converted files would hand them out as standalone files. The pak in a
release is part of the game, read only by it, so it ships in the release
archives and nowhere else. Please do not extract the sounds from it and
redistribute them. A sound whose licence does not allow shipping it in a
game is marked `"shippable": false` in the manifest and left out of release
paks.

## Code and runtime components from others

- **Rust crates**: every dependency compiled into the executable is listed,
  with its licence text, in `THIRD_PARTY_LICENSES.html` in each release
  archive (generated by cargo-about from [`about.toml`](about.toml)). This
  includes the launcher's fonts (SIL Open Font License 1.1, Ubuntu Font
  Licence 1.0).
- **SDL2** is built into the executable (zlib license).
- **SMAA**, the Vulkan renderer's anti-aliasing, is the reference
  implementation by Jorge Jimenez, Jose I. Echevarria, Belen Masia, Fernando
  Navarro and Diego Gutierrez, MIT license
  ([details](crates/inf-game/shaders/smaa/README.md)).
- **Upscalers** (Vulkan, Windows): the port can load AMD FidelityFX FSR 3.1
  (`amd_fidelityfx_vk.dll`, MIT), Intel XeSS (`libxess.dll`, Intel Simplified
  Software License) and NVIDIA DLSS through the port's `inf_ngx.dll` bridge
  (`nvngx_dlss.dll`, `nvngx_dlssd.dll`, NVIDIA RTX SDK license). These
  libraries are not in this repository or in the release archives; placed
  beside the executable, each one's upscaler becomes available
  ([Renderers](README.md#renderers)). Each stays under its vendor's terms.
